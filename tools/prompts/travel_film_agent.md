## The project
Repo: /home/user/cartoon. Code-generated 2D cartoons about cats (Python + Pillow + numpy, 1280x720, 24 fps, flat cartoon style with dark outlines, 2x supersampled), with voices (Kokoro neural TTS, installed, models in build/models), procedural music, synthesized sound effects, burned-in subtitles. **Every film must be exactly 5:55 (355 s)** — the pipeline guarantees it: spoken lines (`Say`) take their speech length, silent action moments (`Act`, weighted) stretch to fill the rest.

Read first: `CLAUDE.md`, `FILMS.md`, `common.py` (format, Say/Act/Voice, shared CAST and SUBTITLE_COLORS, PLACE/LIBRARY, hooks MUSIC/MOODS/MUSIC_CUES/EXTRA_SFX), `draw.py` (Canvas + characters: `cat()` poses stand/walk/sit/sleep/crouch/leap/swim, eyes open/closed/happy/wide, mouth, wet, squash; `mouse()` = Pip; frog, butterfly, moon, tree, bush, flower, cloud, zzz; palettes WHISKERS, LUNA), `audio.py` (MOODS format; built-in sfx meow, splash, clink, whoosh, ribbit, purr; helpers tone/band/env_adsr/place/SR). Reference films: `films/moonfish/` (Film 1, the base patterns: event ids, `tl.t(id, frac)`, `tl.prog`, `actor`, `smooth`, cached wide backgrounds with camera pan, tall backgrounds with tilt, night tint, CONTINUOUS, EXTRA_CUTS) and the finished travel films `films/rome/`, `films/paris/`, `films/montblanc/` (each has story.py, scenes.py, props.py, sounds.py — look at how they did trains, landmarks, new characters, moods, sfx, subtitle readability). You may IMPORT read-only from other film folders (e.g. the room from films/moonfish/scenes.py, a train from another film's props) but never edit them.

- **Luna**: curious, adventurous grey cat, blue collar with a bell; drives the adventure.
- **Pip**: brave little mouse with a red scarf (friend from Film 1). Cameo or bigger role, your choice.

## File rules (several agents work in parallel in this same checkout)
- Create/edit ONLY files inside your own `films/<name>/` folder (`__init__.py`, `story.py`, `scenes.py`, `props.py`, `sounds.py`…).
- Do NOT modify shared files (`common.py`, `draw.py`, `audio.py`, `timeline.py`, `render.py`, `film.py`, README, FILMS.md, CLAUDE.md, catcute/) or other films. If a shared change is truly needed, describe it in your report instead.
- No git commands except `git status`/`git diff`. Do not install packages.

## Quality loop
1. `python3 timeline.py --film <name>` until timing is good.
2. `python3 render.py --film <name> --stills 24` → `out/<name>_contact_sheet.png`; LOOK at it with the Read tool. Check moments with `python3 render.py --film <name> --still <seconds>`. Fix: characters floating/off-screen/badly overlapping, unreadable subtitles (add a soft dark band on bright backgrounds, like montblanc), landmarks that don't read, wrong facing, empty frames. Rich, attractive backgrounds; cache static layers so rendering stays fast (aim < 0.3 s per frame). Iterate several times — quality matters.
3. Final render: `python3 render.py --film <name> --jobs 1` (the machine has only 4 cores shared with 3 other renders — this can take 40–70 min; run it in the background with its log in a file named after your film, e.g. /tmp/render_<name>.log, and wait for it, do not give up). It must end with `duration=355.000000s`. The video is saved to `/root/Desktop/catcute/<PLACE>/<TITLE>.mp4` (+ .srt).

## Final report (compact)
Title, PLACE, the exact output .mp4 path, one-paragraph synopsis, scene list, new characters + Kokoro voices, files created, the final `[done]` render line.
